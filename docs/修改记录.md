## 一、确定 Bug 修复（5 个）

| # | 文件 | 问题 | 修复 |
|---|---|---|---|
| B1 | `sme/space/space.py`、`sme/space/region_manager.py` | ANN 大库路径残留键崩溃风险：`nearest_region` 对 ANN top-1 不校验 Region 存在性；`delete_region` 不清理 ANN，删建数量平衡（Region≥256）时 ANN 残留已删质心 → 写路径 `space.regions[best_id]` KeyError；且 beam 距离混用余弦/欧氏两种度量 | ① beam 全部条目（含 top-1）逐个校验存在性 + 统一精确欧氏距离重排，无有效候选回退全量精确扫描；② `delete_region` 直接使 ANN 失效（`_region_ann = None`），下次构建全量重建 |
| B2 | `sme/retrieval/retriever.py` | BM25 查询/索引分词不一致：索引用 `cjk_bigram=True`（1-2 元），查询侧 `tokenize(query_text)` 默认单字 → 文档侧中文二元组永远无法被查询命中，"违约金→违约/约金"收益打折 | `_keyword_scores` 改为 `tokenize(text, cjk_bigram=self.bm25.cjk_bigram)`，查询与索引同方案 |
| B3 | `sme/benchmark.py` | `eval_set` 在 v2 预设下 id 错位：`add_many` 走提取管线可能丢弃文档，`zip(docs, added)` 错位 → 期望答案全部映射错误，hit@k 失真 | 逐条 `engine.add` 并只登记真正入库的 memory（被丢弃文档不进映射）；并保持 `add_many` 的 bulk 挂起演化语义（修复过程中实测发现逐条 add 会实时触发 Region 演化导致空间结构差异，已一并修正） |
| B4 | `sme/visualization.py` | 坐标系不一致：节点用全体向量 SVD 投影，质心走"单点特判"返回原始前 2 维 → dim>2 时质心星标与 Region 连线画错位置 | 新增 `fit_project_2d`（fit 节点向量得投影基）+ `_ProjectionBasis.transform`（质心经同一基变换），坐标系统一；`project_2d` 原行为保留 |
| B5 | `sme/engine.py` | 跨后端 load 失败：构造时默认 json 后端，加载 sqlite 快照直接抛 "Failed to load snapshot"（对二进制做 JSON 解析） | 新增 `_detect_backend`（sqlite 魔数 `SQLite format 3` 嗅探），load 前自动切换后端再读取；缺失文件保持 json 语义（返回 None） |

**验证**：临时用例 5/5 PASS（ANN 删建平衡不崩溃且 region_id 全部有效；中文 bigram 查询命中；v2 预设 eval 映射正确；投影基线性变换误差 <1e-8；json↔sqlite 双向 load 成功）。用例按约定已删除，核心行为由后续 79 项回归覆盖。
