# SME 接入使用说明

> Spatial Memory Engine —— 新一代 AI 长期记忆系统
> 本文档：安装、配置、接入真实 AI（LLM/Embedding）、Python SDK、REST API、
> 多用户、预设场景、常见问题。
> 实现原理见 [原理解析.md](原理解析.md)，迭代方向见 [迭代计划.md](迭代计划.md)。

---

## 1. 安装

```bash
pip install -r requirements.txt
# 或安装本包：
pip install -e .
# 可选加速：pip install hnswlib（requirements 已含）
# 可选本地 embedding：pip install sentence-transformers torch
#   或：pip install -e ".[local-embeddings]"
```

- Python ≥ 3.10，Windows / Linux 均可用
- **零配置即可离线运行**：内置 hashing embedding，无需任何 API Key
- 可选 extras：`[ann]`（hnswlib 加速）/ `[local-embeddings]`（本地模型）/ `[multipart]`（REST 文件上传）

## 2. 10 秒快速开始

```python
from sme.engine import SpatialMemoryEngine

engine = SpatialMemoryEngine()          # 零配置离线（hashing embedding）

engine.add("用户喜欢苹果")
engine.add("用户每天喝一杯苹果汁")
engine.add("用户周末打篮球")

hits = engine.search("用户喜欢什么水果？", top_k=5)
for h in hits:
    print(h.score, h.memory.text, h.breakdown.to_dict())

engine.reinforce(hits[0].memory.id)     # 命中强化（Ebbinghaus）
engine.visualize("space.png")           # 2D 空间可视化
engine.save("memory_state.json.gz")     # 持久化（JSON+NPZ 双文件）
```

## 3. 配置体系

### 3.1 三种配置方式（同一套 89 项可调项）

| 方式 | 说明 |
|---|---|
| **公共配置 `sme/config.json`** | 随包分发、默认零配置离线、无密钥；通过 `SpatialMemoryEngine(config_path="sme/config.json")` 显式传入（引擎不会自动读取该文件；环境变量 `SME_CONFIG_PATH` 仅 REST 服务端生效，见 3.5）；文件顶部 `_help` 是每项中文说明 |
| **配置菜单 `python -m sme.menu`** | 交互式浏览/修改全部可调项（带说明与校验），**改动立即写回 config.json**；预设一键套用 |
| **代码方式 `SMEConfig`** | 任意一项都可代码设置（见 3.4） |

### 3.2 配置菜单（推荐）

```bash
python -m sme.menu                       # 交互菜单（选组→选项→改值→自动写回）
python -m sme.menu --list                # 列出全部 89 项（含说明）
python -m sme.menu --show                # 查看当前配置内容
python -m sme.menu --check [--ping]      # 验证配置 + LLM/embedding 连通性（含维度校验）
python -m sme.menu --set llm.model=deepseek-v4-flash   # 非交互设置（可多次）
python -m sme.menu --preset kb_static    # 非交互套用预设
python -m sme.menu --config path.json    # 指定配置文件
```

- 手动配置：7 个配置组（LLM 接入 / Embedding 向量 / 记忆会话 / 动力学开关 / 检索与排序 / 存储 / v2 模块），每项显示当前值 + 说明 + 输入格式，**非法输入当场报错**（类型/枚举/范围/必填校验）
- 预设 5 个：01 聊天助手（默认）/ 02 知识库·动态 / 03 知识库·静态 / 04 具身机器人 / 05 全关（裸存取），套用后写回
- 文件容错：配置缺失/为空/损坏自动用默认值重建（损坏文件先备份 `.bak`）；兼容记事本 UTF-8 BOM

### 3.3 `sme/config.json` 配置项总览（89 项）

> `memory` 节是**会话层约定参数**（由接入的聊天程序读取，引擎本身不消费，见 3.3 末注），
> 其余节直接对应引擎配置组；
> 未配置的项自动使用代码内置默认值。

> 注：无参 `SpatialMemoryEngine()` 使用代码内置 dataclass 默认（如 `llm.base_url="https://api.openai.com/v1"`、
> `llm.model="gpt-4o-mini"`、`llm.temperature=0.3`，与下方 config.json 的空默认不同）；
> 无密钥时 LLM 保持未配置（纯离线）。config.json 的值仅在传 `config_path` 时生效。

**LLM 接入（7 项）**

| 项 | 默认 | 说明 |
|---|---|---|
| `llm.base_url` | 空 | OpenAI 兼容端点；留空 = 不使用 LLM（纯离线） |
| `llm.api_key` | 空 | 服务商密钥；留空则 REST 服务模式下可走环境变量（见 3.5），SDK 直连需代码设置 |
| `llm.model` | 空 | 模型名，如 deepseek-v4-flash / gpt-4o-mini |
| `llm.reasoning_effort` | 空 | 推理型模型必须 `none`，否则小 max_tokens 返回空 |
| `llm.max_tokens` | 1024 | 单次回答上限 |
| `llm.temperature` | 0.6 | 随机度 0~2 |
| `llm.timeout` | 60 | 请求超时（秒） |

**Embedding 向量（6 项）**

| 项 | 默认 | 说明 |
|---|---|---|
| `embedding.provider` | hashing | `hashing`（离线零依赖）/ `openai`（任意兼容接口）/ `sentence-transformers`（本地） |
| `embedding.model` | text-embedding-3-small | 本地如 `BAAI/bge-small-zh-v1.5`；接口如 `BAAI/bge-m3` |
| `embedding.dim` | 64 | 必须与模型一致（bge-small-zh=512，bge-m3=1024） |
| `embedding.base_url` | 空 | provider=openai 时必填，如 `https://api.siliconflow.cn/v1` |
| `embedding.api_key` | 空 | 留空则 REST 服务模式下可走环境变量（见 3.5），SDK 直连需代码设置 |
| `embedding.batch_size` | 32 | 批量编码条数 |

**记忆会话（7 项，会话层约定）**：`memory.top_k`（检索条数 6）、`window_rounds`（对话窗口 20）、`consolidate_every`（融合周期 8，off 关闭）、`compress_every`（压缩周期 16，off 关闭）、`graph_expand`（图增强跳数 1）、`reinforce_on`（命中强化 开）、`persist_path`（状态文件路径）

> ⚠️ `memory.*` 这一组是**会话层约定参数**：引擎本身不读取它们（`SMEConfig` 无此节），
> 而是由"接入的聊天程序"读取并按语义落实（`memory.top_k`→`search(top_k=)`、
> `reinforce_on`→`reinforce()`、`graph_expand`→`search(graph_expand=)`、
> `consolidate_every`/`compress_every`→周期调用 `consolidate()`/`compress()`，
> 参考 `大实验/scripts/baselines/sme_adapter.py`）。
> 真正控制引擎返回条数的是调用 `engine.search(q, top_k=N)` 时传入的 `top_k`
> 与 `retrieval.top_k` 候选上限（默认 10，两者可以不同）。

**动力学开关（21 项）**：`policy.decay_enabled`（时间衰减）、`policy.full_memory` / `importance_threshold`（重要度过滤）、`region.auto_evolve`（空间演化）、`region.min_join_cosine`（聚合门槛 0.7）、`region.min_region_size`（最小成员 3）、`region.split_threshold`（拆分阈值 48）、`region.merge_distance`（融合距离 0.12）、`region.ann_enabled`（ANN 加速）、`region.evolve_interval`（演化间隔 40）、`reinforcement.*`（强化半衰期/曲线/增量）、`decay.*`（衰减半衰期 30/最大幅度 0.85）、`consolidation.*`（融合阈值/组上限/摘要方式）、`compression.*`（压缩年龄/最小成员/摘要方式）

**检索与排序（16 项）**：`retrieval.top_regions`（Region 检索数 3）、`top_k`（候选上限 10）、`vector_weight`（0.6）、`keyword_weight`（0.3，0=纯向量）、`metadata_weight`（0.1）、`region_dampening`（0.1）、`cjk_bigram`（中文 1-2 元分词，默认开）、`candidate_window`（候选池下限 20），以及 `ranking.*`（8 项排序权重，建议和=1）

**存储（5 项）**：`storage.path`（快照路径）、`autosave`（自动保存）、`autosave_interval`（100）、`compress`（gzip）、`backend`（json | sqlite）

**v2 模块（27 项）**：extraction（01 提取：enabled/mode）、factversion（05 纠错）、noise（06 噪音：enabled/min_density/template_penalty/dup_penalty）、qapair（02 问答对：enabled/max_age_days）、factgraph（03 图谱：enabled/extract_mode/max_depth）、profile（04 画像：enabled/snapshot_every）、persistence（07 WAL：enabled/checkpoint_every）、api（09 REST：host/port/**auth_token** 鉴权）、observability（10 遥测）、context（11 分层上下文：enabled/budget_tokens）、namespaces（12 多用户：enabled/default_ns）、rerank（13 精排：enabled/model/top_n）

### 3.4 代码方式设置

```python
from sme.config import SMEConfig
from sme.engine import SpatialMemoryEngine

config = SMEConfig()
config.policy.decay_enabled = False          # 关闭衰减
config.region.auto_evolve = False            # 关闭演化
config.storage.path = "my_state.json.gz"
engine = SpatialMemoryEngine(config)         # 或 SpatialMemoryEngine(config_path="sme/config.json")
```

### 3.5 环境变量（仅 REST 服务端生效）

> ⚠️ 所有 `SME_*` 环境变量**仅在 `python -m sme.api` 启动 REST 服务时生效**
> （由 `sme/api/server.py` 的 `build_engine_from_env` 读取）；
> 直接使用 `SpatialMemoryEngine()`（SDK 直连）**不读取任何环境变量**，
> 配置只能走 `config_path` 参数或代码构造 `SMEConfig`。

| 变量 | 作用 |
|---|---|
| `SME_CONFIG_PATH` | REST 服务读取的配置文件路径（等价 `--config`） |
| `SME_LLM_BASE_URL` / `SME_LLM_MODEL` | REST 服务端 LLM 端点/模型（设置了 BASE_URL 才会读 `SME_LLM_API_KEY`） |
| `SME_LLM_API_KEY` | REST 服务端 LLM 密钥 |
| `SME_EMBEDDING_PROVIDER` / `MODEL` / `DIM` / `BASE_URL` | REST 服务端 embedding 配置（设置了 PROVIDER 才会读 `SME_EMBEDDING_API_KEY`） |
| `SME_EMBEDDING_API_KEY` | REST 服务端 embedding 密钥 |
| `SME_API_AUTH_TOKEN` | REST 服务 Bearer 鉴权（等价 `api.auth_token`） |

**SDK 直连时传密钥**：引擎不读环境变量，请自行从环境读取后写入配置：

```python
import os
from sme.config import SMEConfig
from sme.engine import SpatialMemoryEngine

cfg = SMEConfig()
cfg.llm.base_url = "https://api.deepseek.com/v1"
cfg.llm.api_key = os.environ.get("MY_LLM_KEY", "")   # 读你自己的环境变量，不写进文件
engine = SpatialMemoryEngine(cfg)
```

## 4. 接入真实 AI（LLM 与 Embedding）

### 4.1 最小配置（改 sme/config.json 或菜单）

```json
{
  "llm": {
    "base_url": "https://api.deepseek.com/v1",
    "api_key": "sk-xxx",
    "model": "deepseek-v4-flash",
    "reasoning_effort": "none"
  },
  "embedding": {
    "provider": "sentence-transformers",
    "model": "BAAI/bge-small-zh-v1.5",
    "dim": 512
  }
}
```

配置后验证：`python -m sme.menu --check --ping`（发真实请求测连通）。

### 4.2 LLM 服务商对照表（OpenAI 兼容 /chat/completions）

| 服务 | base_url | 备注 |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | 官方 |
| DeepSeek | `https://api.deepseek.com/v1` | 便宜；v4-flash 需 `reasoning_effort=none`；无 embedding 接口 |
| Qwen（通义） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 兼容模式 |
| GLM（智谱） | `https://open.bigmodel.cn/api/paas/v4` | |
| OpenRouter | `https://openrouter.ai/api/v1` | 聚合 |
| SiliconFlow | `https://api.siliconflow.cn/v1` | 聚合，含免费 BGE embedding |
| vLLM | `http://localhost:8000/v1` | 自部署 |
| LM Studio | `http://localhost:1234/v1` | 本地 |
| Ollama | `http://localhost:11434/v1` | 本地 |

> 推理型模型（deepseek-v4-flash 等）务必配 `reasoning_effort: "none"`，否则小 max_tokens 时返回空回复。

### 4.3 Embedding 三选一

| provider | 适用 | 说明 |
|---|---|---|
| `hashing` | 离线演示/零依赖 | 确定性伪向量，中文效果弱于真实模型 |
| `openai` | 任意兼容 API | 需 `base_url` + `api_key` + `model`（如 BAAI/bge-m3, dim 1024） |
| `sentence-transformers` | 本地 | 需 `pip install sentence-transformers`；`model` 如 `BAAI/bge-small-zh-v1.5`（dim 512） |

## 5. Python SDK 完整 API

### 5.1 写入

```python
engine.add(text, metadata={}, tags=[], importance=0.5, source="user",
           link_to=None, link_kind="reference", ns=None)   # 单条 → Memory
engine.add_many([text1, text2, ...])                        # 批量
```

### 5.2 CRUD / 归档

```python
engine.get(mid)                    # 读取（不存在 → None）
engine.update(mid, text=, metadata=, tags=, importance=, weight=, summary=)
engine.delete(mid)                 # 删除 → bool
engine.archive(mid) / engine.restore(mid)   # 冷存储 / 恢复 → bool
engine.list_memories(tag=None, source=None, include_archived=False)
engine.archived_count()
```

> `Memory` 对象字段：id / text / metadata / tags / importance / weight / source /
> archived / parent_id / children / version / created_at / last_hit / hit_count 等。

### 5.3 检索

```python
from sme.retrieval import SearchQuery

hits = engine.search(SearchQuery(
    text="用户喜欢什么水果？",
    top_k=10, top_regions=3,
    metadata_filters={"category": "food"},   # 元数据 AND 精确匹配
    tags=["fruit"],                          # 标签 OR 匹配
    include_archived=False,
    graph_expand=2,                          # 图增强跳数（0=关闭）
))
hits = engine.search("普通查询", top_k=5)             # 字符串简写
hits = engine.search("查询", top_k=5, graph_expand=1) # 简写+图增强
engine.search_regions("水果", top_k=3)                # 仅 Region 检索
```

命中结果 `SearchHit`：`score / memory / breakdown / region_id / region_score /
keyword_score / vector_score / metadata_match`；`breakdown` 含 8 信号分解。

### 5.4 记忆动力学

```python
engine.reinforce(mid)        # 命中强化（Ebbinghaus），返回 delta 明细
engine.apply_decay()         # 持久化衰减因子
engine.consolidate()         # 自动融合 → Summary 记忆（手动触发）
engine.compress()            # 长期摘要（手动触发）
```

### 5.5 记忆图

```python
engine.link(a, b, "conversation")                 # 建边
engine.traverse_graph(mid, kinds=None, mode="bfs", max_depth=3)
engine.build_neighbor_edges(k=5, threshold=0.55)  # 自动邻居边
engine.graph_edges()
```

### 5.6 多用户（namespaces）

```python
engine.add("用户A的秘密", ns="user_a")               # 写：打 ns 标签
hits = engine.search("秘密", top_k=5, ns="user_a")   # 读：只检索该命名空间
view = engine.namespaces.view(engine, "user_a")      # 或视图方式
view.add("用户A的新记忆")
hits = view.search("秘密", top_k=5)
```

不传 `ns` = v1 行为（不过滤）；标签存于 `metadata["ns"]`。
REST/SDK 侧：`MemoryClient.search(..., ns="user_a")` 与引擎参数对齐（内部映射为
`metadata_filters={"ns": ...}`），或直接用 `metadata_filters`。

### 5.7 统计 / 可视化 / 持久化

```python
engine.engine_stats()          # 全量统计（含 v2 模块）
engine.memory_stats() / engine.region_stats() / engine.region_history()
engine.visualize("space.png")
engine.save("state.json.gz")   # JSON+NPZ 双文件；load 自动重建索引
engine.load("state.json.gz")   # 以快照内配置为准（v1+v2 全重绑）
engine.export_json("out.json") # 含向量与 graph 边，可跨引擎导入
engine.import_json("out.json") # 保留原 id 并恢复 graph 边（跨后端 load 自动识别 json/sqlite）
```

## 6. REST API

### 6.1 启动

```bash
python -m sme.api [--config path.json] [--host 127.0.0.1] [--port 8000]
# 或：set SME_CONFIG_PATH=my_config.json 后 python -m sme.api
```

### 6.2 鉴权

`api.auth_token`（或环境变量 `SME_API_AUTH_TOKEN`）非空即启用 Bearer 鉴权：
除 `/health` 与交互文档外，所有请求需带 `Authorization: Bearer <token>` 头。

### 6.3 端点表

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/memories` | 添加记忆 |
| POST | `/memories/batch` | 批量添加 |
| GET / PATCH / DELETE | `/memories/{id}` | 读取 / 更新 / 删除 |
| POST | `/memories/search` | 两阶段检索（支持 graph_expand/metadata_filters） |
| POST | `/memories/{id}/hit` | 命中强化 |
| POST | `/memories/{id}/archive` `/restore` | 冷/热存储 |
| GET | `/regions` · POST `/regions/search` `/regions/evolve` | Region 列表 / 检索 / 演化 |
| GET | `/stats` | 统计 |
| POST | `/consolidate` `/compress` | 融合 / 压缩 |
| GET | `/graph` · POST `/graph/link` | 记忆图 |
| GET | `/export` · POST `/import` `/import/file` | 导出 / 导入 |
| GET | `/visualize` | 渲染空间图 PNG |
| GET | `/facts` · POST `/facts/multi_hop` | 知识图谱（模块 03） |
| GET | `/profile` | 用户画像（模块 04） |
| GET | `/qapairs` | 问答对（模块 02） |
| GET | `/metrics` | 遥测（模块 10） |
| GET | `/metrics/report` | 遥测 JSON 报告下载（模块 10） |
| GET | `/health` | 健康检查 |

```bash
curl -X POST http://127.0.0.1:8000/memories -H "Content-Type: application/json" \
  -d '{"text": "用户喜欢苹果", "tags": ["fruit"]}'
curl -X POST http://127.0.0.1:8000/memories/search -H "Content-Type: application/json" \
  -d '{"text": "用户喜欢什么水果？", "top_k": 5, "graph_expand": 1}'
```

> `/memories/search` 响应不含 embedding 向量（轻量）；单条 GET/POST/PATCH 与 `/export` 含向量。

### 6.4 Python SDK（MemoryClient）

```python
from sme.api.client import MemoryClient

sdk = MemoryClient("http://127.0.0.1:8000", api_key="token")   # api_key 可选（鉴权时必填）
m = sdk.add("用户喜欢打篮球", tags=["sport"])
got = sdk.get(m["id"])          # 404 → None（与 engine.get 对齐）
r = sdk.search("喜欢什么运动", top_k=3)
sdk.delete(m["id"])             # → bool（与 engine.delete 对齐）
sdk.close()
```

方法与引擎同名：add / add_many / get / update / delete / archive / restore /
reinforce / search / regions / search_regions / evolve_regions / consolidate /
compress / stats / graph / graph_link / facts / facts_multi_hop / qapairs /
profile / metrics / export / import_memories / visualize / health。

> `search(..., ns="user_a")` 客户端内部映射为 `metadata_filters={"ns": "user_a"}`；
> `visualize(save_to)` 返回 PNG bytes（与引擎 `visualize(path)` 写文件的语义不同）。

## 7. 预设场景推荐

| 场景 | 推荐配置 | 说明 |
|---|---|---|
| 日常对话陪伴 | 01 聊天助手（默认） | 强化/衰减/融合/压缩全开，动态记忆 |
| 知识库（允许提权） | 02 知识库·动态 | 知识不衰减不融合，越查越重要 |
| 知识库（纯只读） | 03 知识库·静态 | 检索不改任何状态，结果可复现 |
| 具身机器人/嵌入式 | 04 具身机器人 | WAL 崩溃安全 + 多用户隔离 + 规则提取 + 记忆稳定 |
| 普通向量库 | 05 全关（裸存取） | 所有动态机制关闭 |

> 经验：v2 模块（提取/噪音/问答对）面向**中文对话**设计；英文/闲聊场景建议
> 保持 v1 原生配置或按需只开 05/02/04/03（无损增强）。全开并非最优配置。

## 8. 持久化与数据安全

- 快照双文件：`state.json[.gz]`（文本/元数据）+ `state.embeddings.npz`（向量侧车），原子写入（tmp+rename，崩溃不损坏）
- 归档冷存储独立文件，恢复无损；记忆**永不因衰减被删除**
- 备份：复制 `state.json.gz` + `state.embeddings.npz`（两者需成对保存）
- **REST 服务模式**：密钥走环境变量 `SME_LLM_API_KEY` / `SME_EMBEDDING_API_KEY` / `SME_API_AUTH_TOKEN`，不落盘（见 3.5）
- **SDK 直连模式**：引擎不读环境变量，运行时从你自己的环境变量读入 `SMEConfig`（示例见 3.5），
  或把含密钥的配置文件放在不入库的路径（如 `~/.sme/config.json`）用 `config_path` 加载
- `sme/config.json` 随包分发的默认配置不含任何密钥（密钥字段为空），可安全入库；引擎运行时状态文件（`data/`）已加入 .gitignore
- `load()` 后以快照内保存的配置为准（v1+v2 全部配置组均重绑）

## 9. 常见问题（FAQ）

**Q1：LLM 返回空字符串？** → 模型是推理型（如 deepseek-v4-flash），配置 `llm.reasoning_effort = "none"`。

**Q2：本地模型怎么用？** → `embedding.provider = "sentence-transformers"`，`model = "BAAI/bge-small-zh-v1.5"`（需 `pip install sentence-transformers`）。

**Q3：记忆会丢吗？** → 不会。衰减只降低命中概率永不删除；归档可恢复；快照原子写防损坏；WAL 崩溃自动恢复（保留原 id）。

**Q4：怎么让记忆永不变化（纯知识库）？** → 预设 03 知识库·静态：衰减/演化/强化全关 + 不调用 consolidate/compress。知识库预设已调高语义排序权重（semantic 0.45 / freshness 0.04 / recency 0.02）。

**Q5：中文效果差？** → 换更强 embedding（如 BGE-m3）。1.2 起 BM25 关键词通道默认启用中文 1-2 元切分（违约金→违约/约金，`retrieval.cjk_bigram` 可关）；文档资料用 `engine.import_documents` 分条入库（自动条款 metadata，`metadata_filters` 圈定）。

**Q6：检索结果能解释吗？** → 每条结果带 `breakdown`（semantic/importance/freshness/weight/decay/hit_count/recency/region 八信号分解）。

**Q7：graph_expand 是什么？** → 在向量相似之外沿记忆图（conversation/reference 等边）扩展关系相关的记忆；top_k//5 槽位预留给图扩展节点。

**Q8：性能如何？** → 1.1 起写入路径改为质心增量更新 + 几何延迟计算：10k 条写入 ~4s（2472/s，旧实现 O(N²) 需 118s）；100k 条加载 ~3s、保存 ~3.3s；hashing 检索 p50 ~4.3ms（2k 条）/ ~22ms（10k 条，2026-08 实测）。大库（≥256 Region）自动启用 ANN 加速。

**Q9：load 后配置变了？** → 快照内含配置，load 以快照为准（全量重绑，含检索/排序/策略/空间参数）。

**Q10：如何接 REST？** → `python -m sme.api`，文档在 `http://127.0.0.1:8000/docs`；SDK 用 `MemoryClient`；生产环境建议设 `api.auth_token` 或用反向代理。

**Q11：多用户怎么用？** → 写入/检索传 `ns` 参数（`engine.add(..., ns="user_a")`），或 `engine.namespaces.view(engine, ns)` 视图；REST 用 `metadata_filters={"ns": "user_a"}`。
