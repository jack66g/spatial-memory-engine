# SME 程序原理解析

> Spatial Memory Engine（SME）—— 新一代 AI 长期记忆系统
> 本文档：整个程序的原理 + 每个文件的作用 + 每个函数的作用（函数级解析）
> 配套文档：[接入使用.md](接入使用.md)（如何接入）、[迭代计划.md](迭代计划.md)（对标第一梯队）

---

## 一、一句话简介

SME 不是传统向量数据库（Memory → Embedding → TopK），而是一个**空间记忆引擎**：
全部记忆构成连续 Embedding 空间，写入时自动形成**密度驱动的 Memory Region**
（动态增长/拆分/融合），Region 之间构成图连接；记忆之间另有六种语义边构成
Memory Graph。在此基础上叠加**记忆动力学**（Ebbinghaus 强化、时间衰减、自动
融合、长期压缩）与**两阶段混合检索**（Region 主导召回 + 向量/BM25/metadata
混合 + 可选图增强），为 AI 提供具备"记忆生命周期"的长期记忆能力。

```
传统 RAG:  Query → Embedding → 全库 TopK → LLM
SME:       Query → Embedding → Region Retrieval(Top1/3/5)
                              → Hybrid Retrieval(向量+BM25+metadata)
                              → Graph Expansion(可选)
                              → Memory Ranking(FinalScore 8 信号) → LLM
```

v2 层（12 个模块 + 可选精排，全部 `enabled=False` 默认关，全关 = v1 行为）在其上补齐：
事实提取（01）、问答对（02）、知识图谱（03）、用户画像（04）、事实版本纠错（05）、
噪音抑制（06）、WAL 增量持久化（07）、存储后端（08）、REST+SDK（09）、可观测性
（10）、分层上下文（11）、多用户隔离（12）、可选 Rerank 精排（13）。另有知识库文档导入工具（`sme/import_docs.py`）。

## 三、核心流程

### 3.1 写入流程

```
engine.add(text, metadata, tags, ..., ns)
  ├─ v2 未激活（active()=False）→ memory_manager.add_memory（v1 直通）
  └─ v2 激活 → WritePipeline.run(ctx)：
       ExtractionStage(01)      : 提取事实 / 纠错语气标记 / 余弦去重
       CanonicalStage(01/05/02) : 版本化 resolve + "存什么"决策（直通/问题/事实）
       StorageStage(02/03/04)   : 逐条落库 + 问答对挂接 + 图谱/画像写入
       AnswerCaptureStage(02)   : 助手回答 → 问答对回放条目
  → WAL 追加（模块 07，可关）→ telemetry（模块 10，可关）→ autosave
```

### 3.2 检索流程

```
engine.search(query, top_k, ..., ns)
  ├─ v2 search_pre：qapair 直接回放（问题→已存答案，0.99 分置顶）
  ├─ retriever.search（v1 两阶段）：
  │    Stage1 Region 检索：全 Region 粗排（0.6×cos+0.4×距离）→ top(k×4,≥12) 精排
  │    Stage2 Hybrid：Region 成员 + 预算型全局补充 → 向量/BM25/metadata 加权
  │    → graph_expand：沿记忆图 BFS，0.5^depth 衰减，top_k//5 槽位
  │    → MemoryRanker：8 信号 FinalScore（detailed 仅 top-k 计算）
  └─ v2 search_post：factgraph 多跳扩展 → noise 重排 → profile 加权
                     → factversion 旧版降权 → qapair 问题句惩罚
```

### 3.3 空间演化流程

```
insert(memory_id, vector)
  ├─ 无 Region → create_region
  ├─ 最近 Region 余弦 ≥ min_join_cosine → 加入并 refresh_geometry
  └─ 否则 → 新建 Region
write_ops % evolve_interval == 0 → evolution_pass：
  ├─ split：size≥48 且 density≥120 且距上次 merge 够远 → 二分裂（大块保留原 id）
  ├─ 小 Region 吸收：size<3 → 并入最近邻
  └─ 邻近融合：Region 边距离 <0.12 且合并规模合规 → 小并大
（候选集增量维护：_split_candidates/_small_candidates/_close_edge_keys）
```

## 六、关键机制速览

| 机制 | 说明 | 关闭方式 |
|---|---|---|
| Region 演化 | 密度驱动 split/merge/吸收 + ANN 加速；写入路径质心增量更新（与全量 mean 数学等价，误差 ~1e-17），半径/密度/bbox 延迟到消费时刻精确重算（写入从 O(N²) 降为近线性） | `region.auto_evolve=False` |
| 两阶段检索 | Region 粗排 → 区域内混合（向量+BM25+metadata）→ 预算补充（候选池 ≥ max(top_k×2, `candidate_window`)） | `retrieval.*` |
| 8 信号排序 | semantic/importance/freshness/weight/decay/hit_count/recency/region（weight/importance 用有效值；freshness 按最后命中时间随衰减半衰期衰减，不再是恒 1.0 死信号） | `ranking.*` 权重 |
| 强化/衰减 | Ebbinghaus 半衰期 7 天 / 指数衰减半衰期 30 天（下限 15%，永不删除） | 不调用 reinforce / `policy.decay_enabled=False` |
| 融合/压缩 | 手动触发（engine.consolidate/compress 或 REST） | 不调用 |
| 图增强 | 记忆图 BFS，0.5^depth 衰减，top_k//5 槽位 | `graph_expand=0` |
| v2 写管线 | extraction→canonical→storage→answer_capture（WritePipeline 注册制） | 各模块 `enabled` |
| v2 检索钩子 | qapair 回放 / factgraph 多跳 / noise 重排 / profile 加权 / 版本降权 | 各模块 `enabled` |
| 持久化 | JSON+NPZ 双文件快照（原子写）/ SQLite（WAL 写入库内 wal_ops 表）/ WAL 增量（可关） | `storage.backend`、`persistence.enabled` |
| 多用户 | `engine.add/search(ns=...)` metadata 标签隔离；qapair 回放/图谱扩展同样按 ns 过滤 | `namespaces.enabled` |
| REST 鉴权 | `api.auth_token` 非空启用 Bearer | 留空 |

## 七、设计决策要点

| 决策 | 理由 |
|---|---|
| Region 密度驱动而非 KMeans | 流式写入无需重聚类，Region 数量自适应数据 |
| 余弦阈值随 provider 自适应 | hashing(0.70) 与真实 embedding(0.55) 余弦分布不同 |
| 两阶段 + 预算型全局补充 | Region 主导召回，同时不遗漏强记忆 |
| 演化候选集增量维护 | 单次演化 O(候选数) 而非 O(R²) |
| split 保留大块原 id | 外部引用（memory.region_id、图边）不失效 |
| 图扩展保留槽位 | 纯分数合并会让深度衰减的图节点永远不可见 |
| BM25 增量倒排 + CJK 1-2 元 | 避免每查询全量重建；中文按二元切分（违约金→违约/约金），`retrieval.cjk_bigram` 可关 |
| hnswlib 可选 + 精确回退 | 无强依赖也能跑，度量语义统一 |
| 快照 JSON+NPZ 双文件 | 文本小巧快读，向量二进制紧凑（省 ~50% 体积） |
| load() 全量重绑快照配置 | 恢复后行为与保存时一致（v1+v2+LLM+冷档案） |
| WAL 重放保留原 id | 崩溃恢复后引用不断裂 |
| 写路径可插拔 Stage | v2 模块设计 5.1 落地，模块 flag 驱动惰性 |
| 全部可关闭 | 全关 = 纯 v1 行为，快照格式不变 |
