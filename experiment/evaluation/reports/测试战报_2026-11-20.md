### 2.2 各信号/旋钮敏感度(单坐标,Δcomposite vs 基线)

- **semantic**:唯一正贡献信号;归零 -0.178(灾难),×2 +0.163。**最优点在边界(=1.0)**
- importance/freshness/weight/decay/recency:默认值下归零反而 **+0.015~+0.041**(静态评测中纯噪声);但见 §4 纵向实验——它们是"越用越顺"的收益载体,不是无用
- hit_count/region:≈中性(±0.005)
- 融合通道:hashing 向量弱于 BM25(纯向量 0.171 vs 纯关键词 0.399);**weighted 旧融合 0.168 << minmax 0.238**(minmax 优 +42%)
- keyword_candidates:默认 0 是漏油点,+20 = **+0.055**(白捡)
- top_regions:1 优于 3(+0.016),8 = -0.034
- 衰减族:decay off +0.081 / 半衰期 365d +0.083 / max_weight_decay=0 +0.049(方向一致:静态有害)
- noise 模块开 = -0.029;qapair/factversion 开 = -0.013(此数据上无益)
- min_similarity 默认 -1(关闭)无影响;query_cache_size/summary_penalty 无显著影响

## 3. Bug 清单(只读发现+运行时实锤)

### P2(结果错误/功能失效,运行时实锤 6 项)
1. **import 毒数据检索除零**:`import_memories` 不校验,hit_count=-1 → `ZeroDivisionError`,一次 search 全库崩(REST /import 同样,500)。实锤
2. **NaN importance 穿透**:SDK/REST 传 NaN 过 clamp(min/max 吞 NaN),排序分变 NaN,结果不可预测。实锤
3. **热重建 mrl_dim 闸门缺失**:PUT /config 改 embedding.mrl_dim(库非空)闸门放行 → 新 32 维向量入 64 维 Region → `ValueError: shapes (5,64) (1,32)`,库永久不可用。实锤
4. **多进程并发写同路径**:3 进程 ×20 条 → 终态 20/60(last-writer-wins 丢写);竞态交错还可产出**孤儿快照**(json.gz 在、embeddings.npz 缺)→ load() 直接崩。上游无跨进程锁(插件线已知,上游裸奔)。实锤
5. **混合拉丁+CJK 分词**:"GPT4模型"整词从 BM25 索引消失(utils.py tokenize 把混合 run 按 CJK 拆散);当前被向量通道掩盖,keyword_weight 高时显形。静态确认,运行时被向量通道救回
6. **演化候选饥饿**:同轮超阈 Region >8 个时,超额候选被无条件 clear,大 Region 可能永不拆分(region_manager.py:330-381)。静态确认

### P3(边界/条件触发)
7. cold_archive.json 损坏 → 引擎构造直接崩(无 try,archive.py:26)。实锤
8. from_dict 零校验:evolve_interval=0 → 每次写入 ZeroDivisionError。实锤
9. SDK update() 接受纯空白文本入库;add_many importance 不 clamp(7.5 直接入库)。实锤 ×2
10. 注册表与 dataclass 默认不一致:llm.temperature 0.6 vs 0.3、llm.model "" vs "gpt-4o-mini"(SDK 直构 vs 配置文件初始化行为不同)。实锤

### A. 跨进程写锁(上游从无到有)

| 组件 | 内容 |
|---|---|
| sme/storage/xlock.py(新) | msvcrt/fcntl 独占锁,覆盖"读谱系→落盘→推进谱系"整段;线程级重入表(防 load→WAL恢复→save 嵌套自锁);崩溃由 OS 自动释放 |
| 丢更新防护 | 锁文件偏移 16 记录写入者谱系 (pid, n),仅成功 save 推进;save 前发现谱系被他人推进 → 如实 RuntimeError,绝不静默覆盖 |

实测:3 进程 × 20 条并发风暴 **60/60 零丢失零撕裂**(load-first + 冲突重载合并);lost-update 场景 A 的覆盖保存被如实拒绝;锁超时如实抛 CrossProcessLockTimeout。

**实现中消灭的四个自坑(全记录)**:①yield 写进 threading.Lock 块内 → 同线程重取锁死锁(改为 guard 内判定、guard 外 yield);②文件 mtime 指纹判据对 sqlite(WAL 与快照同库)全是误报 → 改谱系判据;③锁文件 a+b 追加模式 seek+write 无效 → O_RDWR|O_CREAT;④锁住首字节后另开句柄读写被 OS 拒 → 谱系读写走持锁句柄本身。
**已知边界**:WAL 逐条追加不在锁内(跨进程 WAL 交错仍未定义,文档已注明);mtime 相同刻度的理论竞态以"严格大于"收窄。
